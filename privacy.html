Privacy & Compliance Statement

PromptSafe is designed from the ground up to be the most privacy-respecting secret scrubber available. This document explains exactly what data practices we follow and why.

GDPR Compliance

Article 5 — Data minimisation: PromptSafe processes text entirely in your browser. No personal data is transmitted, stored, or retained. There is no server-side component to hold data.

Article 25 — Data protection by design: The application is a single HTML file with zero external dependencies beyond a cached stylesheet. No cookies, no local storage, no tracking pixels, no analytics.

Article 32 — Security of processing: All processing happens client-side using deterministic regular expressions. There is no network transmission of any kind during scrubbing. You can verify this by opening your browser's Network tab and confirming zero requests are made.

Article 33 — Breach notification: Because no data leaves your browser and nothing is stored on any server, there is no breach vector. Your data never reaches a system that could be compromised.

CCPA Compliance

Right to know: PromptSafe collects zero personal information. There is nothing to disclose because nothing is collected.

Right to delete: Because no data is stored anywhere, there is nothing to delete. Closing the tab destroys all traces of your input.

Right to opt-out of sale: PromptSafe does not sell, share, or transmit any data. There is nothing to opt out of.

Non-discrimination: There is no user account system, no tracking, and no profiling. All users receive the identical experience.

Technical Architecture

Single file: The entire application is one HTML file. No build step, no package manager, no server component.

Zero backend: There is no API, no database, no cloud function, no server-side processing. The app works fully offline after the first load.

Zero storage: PromptSafe does not use cookies, local storage, session storage, IndexedDB, or any other persistence mechanism.

Zero network: During text processing, no network requests are made. The only network request is the Tailwind stylesheet at page load, which is cached by the browser.

Open source: The complete source code is available on GitHub under the MIT license. You can audit, fork, and self-host it.

Verify It Yourself

Don't take our word for it. Here is how to verify our privacy claims in under a minute:

  1. Open your browser's Developer Tools (F12)
  2. Select the Network tab and clear it
  3. Paste text containing secrets into PromptSafe
  4. Watch the Network tab — no requests are made
  5. Set throttling to "Offline" and keep scrubbing — it still works
  6. Read the source code — it is one file, available on GitHub
