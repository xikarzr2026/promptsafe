# Review sweep — 2026-10-21

Four reviewers each took one area (detection engine, web UI, CLI + REST server,
extension + build tooling) and proposed changes with reproductions. An
administrator challenged each proposal. Some were accepted as written, some
were sent back for rework (sometimes more than once), and some were trimmed or
rejected. Only changes both sides agreed improved the product were implemented.

Final state: `npm test` passes (engine 53/53, integration + extension 41/41,
web-security check). The restore flow, the ANSI compress fix and the CSP were
also checked by hand in a browser over local HTTP.

## Rejected or deferred

- **Prefix match on extension `selectionText`**: rejected. The evidence was a Firefox bug, the target is Chrome, and the exact match fails closed.
- **Icon generator port-0 / load-event rework**: rejected. It's a contributor-only tool and the PNGs are committed.
- **Temp-file-and-rename for CLI `-o`**: rejected as unnecessary once same-file writes are refused.
- **Splitting unquoted creds values on `,` and `;`**: documented rather than fixed (inherently ambiguous).
- **`.gitattributes` (`eol=lf`)**: deferred. It renormalizes every file and should be its own commit after the current uncommitted work lands.
