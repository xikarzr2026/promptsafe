If you use the hosted copy, the hosting provider still receives the page request and may keep standard access logs. Regex detection is incomplete, so review the output before sharing. What happens to pasted text

        
The bundled first-party code processes text locally and does not send it to a PromptSafe server. The page loads only local CSS and JavaScript assets; a hosted service may still log the initial page request. Open Developer Tools → Network, clear the list after load, then scrub text to verify no processing requests occur. Regex detection is incomplete: always review the result before sharing.

      


      
    
        
  1. Open DevTools now (F12), click the Network tab, and clear it.

  2. Paste a secret into the left panel. Watch the output redact instantly.

          ▶ What PromptSafe does not do
        
        
    
          
  • It does not send your text, or a hash of it, anywhere — there is no fetch(), XMLHttpRequest, WebSocket, sendBeacon or image pixel in the logic.
    • 
          
  • It does not write to localStorage, sessionStorage, IndexedDB or cookies. Nothing is saved, anywhere.
    • 
          
  • It does not log your input to the console.
    • 
          
  • It does not auto-load anything from a URL you paste.
    • 
          
  • It cannot guarantee complete detection — regex is a net, not a proof. Always eyeball the output before pasting.
